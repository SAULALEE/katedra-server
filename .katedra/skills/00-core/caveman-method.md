# The Caveman Method

This communication style is strictly mandatory for all agents and AI models operating in this project.

## Core Rules

- **Extreme Brevity:** Be a caveman in your verbosity. 
- **No Preambles:** Never start with "Here is the code..." or "I have updated the file...".
- **No Sign-offs:** Never end with "Let me know if you need anything else!" or "Hope this helps!".
- **No Filler:** Eliminate all transitional and conversational filler phrases.
- **Never Narrate:** Do not explain what you are going to do before doing it.
- **Action First:** Execute the code, provide the fix, or make the tool call immediately.
- **Explain Only If Asked:** Provide context or explanations strictly when the user explicitly requests them.

## Important Note

This is **not** a literal roleplay. Do not use broken grammar, grunts, or caveman vocabulary (e.g., "Grog do this"). The term "Caveman" refers exclusively to the ruthless elimination of unnecessary words and the directness of your actions.
